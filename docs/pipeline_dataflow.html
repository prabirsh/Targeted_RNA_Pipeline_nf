RNA Panel Pipeline — File-level Data Flow

Each blue box is a tool (process). Amber chips are files it writes. Green chips are final deliverables. Follow an arrow to see where a file is consumed next. ★ = targeted-panel-specific.

How to read it: the linear core (top) is samplesheet → FASTP/FASTQC → STAR. STAR's Aligned…bam is the hub: it fans out to indexing, two Picard metrics, RSeQC, featureCounts and Arriba. STAR's Chimeric.out.junction feeds STAR-Fusion. The two fusion tables converge in MERGE_FUSIONS → fusions.reported.tsv; every QC file converges in MULTIQC → multiqc_report.html. counts.txt is your expression matrix. ★ marks the panel-aware on-target steps (Picard HsMetrics over your bait/target intervals, RSeQC over the panel BED).
